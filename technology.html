Small models, built for one job.

A general large model answers everything and can invent facts when it is unsure. We train compact models on one domain, test them against that domain, and deploy them where the data already lives.

Domain SLMs compared with general LLMs

General-purpose LLMIndiCloudAI domain SLM
Training dataBroad internet textCurated, domain-specific data
ReliabilityCan produce confident, unsupported answersConstrained to one task, with measurable accuracy
Where it runsLarge remote infrastructureOn the device or in an Indian data centre
Data exposurePrompts often leave the countryData stays where it is created

Our model pipeline

  1. Start with an Indic teacherA multilingual model that understands Indian languages.
  2. Distil to a studentKnowledge distillation with temperature scaling and a combined KL and cross-entropy loss.
  3. Quantise and exportINT8 ONNX keeps accuracy while cutting size and compute.
  4. Test before releaseA 138-case suite exposes blind spots before users do.

How testing shapes the model

Our pre-release suite found weak spots in tech-support, delivery and minority-language scam patterns, and a tendency to misclassify KYC scams. We also found false positives from system notifications and fixed them with a package-name whitelist. We publish this because honest evaluation is part of building a reliable domain model.

Cloud architecture

Our models run on-device. Cloud is used for training, data preparation, evaluation and, as we add business customers, hosted APIs and dashboards. We design for any major provider by using containers and open model formats such as ONNX, and we deploy in Indian regions so data stays in the country.

Preview

API and playground.

The model is available through a REST API, and the playground uses it so you can try messages yourself. For now the preview runs on a demo server outside India (currently Singapore). We plan to move it to an Indian cloud region.

Our service does not store submitted text. See the model card for what the model is and where it falls short.

{
  "label": "kyc_fraud",
  "confidence": 0.97,
