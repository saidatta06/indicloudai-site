Data stays in India by design.

Privacy and security are part of how we build, not an add-on. This page explains what we do and what we do not yet claim.

Data residency

On-device first
Where possible, inference runs on the user’s own device, so there is nothing to transmit or store.
India-resident cloud
Any cloud workload runs in Indian regions, so training data, prompts and outputs remain in the country.
Data minimisation
We collect only what a feature needs and do not sell personal data.

Security practices

Identity and access
Least-privilege roles, multi-factor authentication and Zero Trust principles across all environments.
Encryption
TLS for data in transit and encryption at rest for stored data.
Secure development
Code review, dependency checks and a pre-release test suite before every model or app release.
Transparency
Apps explain each permission before requesting it.

Compliance position

We design with India’s Digital Personal Data Protection Act, 2023 in mind and support the rights it gives individuals. IndiCloudAI is an early-stage company and does not yet hold formal certifications such as ISO/IEC 27001 or SOC 2. We will say so on this page when that changes.

Report a vulnerability

If you find a security issue in our website or apps, email saidatta@indicloudai.in with the details. Please give us reasonable time to fix it before sharing it publicly. Our contact details are also in security.txt.
